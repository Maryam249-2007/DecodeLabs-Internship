# Phishing Awareness Analysis

## Overview
This project focuses on identifying phishing attempts by analyzing simulated emails and messages. It helps recognize common phishing indicators such as suspicious links, fake domains, urgent language, and requests for sensitive information.

## Objectives
- Identify phishing indicators in emails.
- Detect suspicious URLs and keywords.
- Analyze phishing red flags.
- Classify messages based on risk level.
- Improve cybersecurity awareness.

## Features
- Sender analysis
- URL analysis
- Keyword analysis
- Risk classification
- Phishing red-flag checklist
- Security recommendations

## Tools Used
- Microsoft Word
- PDF Documentation

## Project Outcome
The project demonstrates how phishing attacks can be recognized using manual analysis and risk assessment techniques, helping users avoid common cyber threats.
